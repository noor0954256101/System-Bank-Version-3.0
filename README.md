# Bank Management System – User Permissions

A C++ console-based banking management system that combines client management, banking transactions, user authentication, and permission control.

## Features

* User login and authentication
* Role-based permission system
* Manage bank clients
* Add, delete, update, and search clients
* Deposit and withdraw money
* Display total balances
* Manage system users
* Add, delete, update, and search users
* Assign specific permissions to users
* Full-access administrator permission
* File-based data storage
* Console-based menu system

## Permissions

The system allows administrators to control access to different features:

* Show Client List
* Add New Client
* Delete Client
* Update Client
* Find Client
* Perform Transactions
* Manage Users
* Full Access

## Concepts Used

* C++
* Structs
* Vectors
* Functions
* Enums
* Bitwise Operators
* File Handling
* CRUD Operations
* Data Validation
* User Authentication
* Permission Management
* Modular Programming

## Data Storage

The application stores client and user information in text files and converts the stored records between strings and C++ structures using a custom delimiter.

## Project Goal

The project was built to practice developing a more realistic C++ system by combining file handling, CRUD operations, authentication, permission management, and banking transactions into one application.
